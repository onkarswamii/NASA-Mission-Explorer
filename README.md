# 🚀 NASA Mission Explorer

## 📌 Description
A web application that fetches data from NASA's Astronomy Picture of the Day (APOD) API and displays space images/videos.

## 🌐 Live Demo
https://nasa-mission-explorer.netlify.app

## ⚙️ Features
- Fetch data using NASA API
- Display multiple space images/videos
- Search images by title
- Filter (Image / Video)
- Sort by date (Newest / Oldest)
- Dark/Light mode toggle
- Fullscreen image modal
- HD image view

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API

## 🔗 API Used
https://api.nasa.gov/

## ▶️ How to Run
1. Clone repository
2. Open index.html in browser
