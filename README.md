# 🚀 NASA Mission Explorer

## 📖 Project Overview

NASA Mission Explorer is a web application that allows users to explore NASA's **Astronomy Picture of the Day (APOD)**. The application fetches real-time data from NASA’s public API and displays beautiful space images along with their titles, dates, and explanations.

Users can select a specific date to discover what the universe looked like on that day. The application aims to provide an engaging and interactive way to explore NASA's astronomical content.

This project demonstrates the use of **JavaScript, API integration, and dynamic UI development**.

---

## 🌌 Project Purpose

The purpose of this project is to build a responsive web application that interacts with a public API to fetch and display real-time data. It helps users explore space imagery provided by NASA and learn how to work with APIs in JavaScript.

---

## 🔗 Public API Used

This project uses the **NASA Open API**.

API Website:
https://api.nasa.gov/

Endpoint used in this project:

https://api.nasa.gov/planetary/apod

The API provides:

* Astronomy Picture of the Day
* Image title
* Description
* Date
* High-resolution image links

## ✨ Planned Features

### 📅 Date Picker

Users can select a specific date to view the Astronomy Picture of the Day for that date.

### 🖼️ Image Gallery

Display the image along with:

* Title
* Date
* Description

### 🔍 Search Functionality

Users will be able to search images by title.

### 📊 Sorting

Users can sort results by date (newest to oldest or vice versa).

### 🧭 Filtering

Filter content based on media type (image or video).

### 🔍 Full-Screen Image Modal

Clicking on an image will open it in a full-screen modal view.

### 🌠 HD Image Toggle

Users can switch between normal resolution and HD resolution images.

### 📱 Responsive Design

The application will work properly on mobile, tablet, and desktop screens.
